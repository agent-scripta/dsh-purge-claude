# purge 命令清单（Claude 专版）

小码酱按需注入 —— 默认正常会话，用下面命令按需切换；切换后**新开会话**生效。

> 插件装法命令带命名空间 `/purge:`；独立 skill 装法用裸 `/purge`，参数写在命令后（如 `/purge max`）。

| 插件命令 | 独立 skill | 作用 |
|---|---|---|
| `/purge:purge-panel` | 控制面板 · 状态/档位/命令一览（纯文本） |
| `/purge:purge-on` | `/purge on` | 默认档 · 通用协作（当前规则集） |
| `/purge:purge-max` | `/purge max` | 最硬档 · 强规则完整版（不软化，建议配强模型） |
| `/purge:purge-redteam` | `/purge redteam` | 红队评测模式 |
| `/purge:purge-minimal` | `/purge minimal` | 极简 · 只保留身份与基本工作方式 |
| `/purge:purge-stealth` | `/purge stealth` | 隐身 · 低痕迹执行，反调试/免杀等本地测试 |
| `/purge:purge-novel` | `/purge novel` | 创作 · 角色扮演/小说/成人向，写足不淡出 |
| `/purge:purge-off` | `/purge off` | 关闭 · 恢复正常 Claude Code |
| `/purge:purge-status` | `/purge status` | 查看当前模式 |

## 注意
- web(ClaudeCN) 真正生效的是服务端 `/data/.claude/claude-cn/cyber-risk-instruction.md`（切档时写入、off 删除、SessionStart 自愈同步）。
- 卸载：`bash uninstall.sh`。
